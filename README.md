# Mae-C-A-modified-Priority-Scheduling-System
My own take to optimize the priority scheduling system. This was inspired by the age gap of me and that special someone whom I really want.
Note that this Scheduling System works best with a large gap random number. Example a combination of low burst/arrival and large burst/arrival time.
